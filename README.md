# Self Search
Search across multiple self-hosted services at once.

Supported:
- SearXNG
- Immich
- Jellyfin
- Navidrome
- BookStack
- Audiobookshelf
- DuckDuckGo

Features:
- OIDC authentication
- Per-user configuration
- In-browser configuration for services
- List of services above search shows if there was an error

## Get Started
Docker compose:
```yaml
services:
  unified-search:
    build: .
    container_name: unified-search
    ports:
        - "8080:8080"
    volumes:
        - ./data:/app/data
    environment:
        - OIDC_CLIENT_ID=3hd31qLKB8O9agTgh1GviGbLfiMoAcVLeIOULgeh
```
